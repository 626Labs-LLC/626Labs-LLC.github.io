Privacy Policy — Discord Applications

Effective 2026-07-04 · Covers the Discord applications operated by 626Labs LLC: 6deux6, 626 Labs, and RoRoRo.

The short version: we collect as little as possible, and for most of these apps that means nothing about you at all. We don't sell data, we don't run ads, and we don't track you.

6deux6 (release feed bot)

6deux6 posts software release announcements to Discord channels it is invited to. It does not read messages, and it stores no user data of any kind — no message content, no usernames, no user IDs. Its only stored state is a list of public software version numbers, kept in a public JSON file. When its optional announcement-writing feature is enabled, the only text processed by an AI model is our own public release notes.

626 Labs (community bot)

The 626 Labs bot operates the 626Labs community server. It processes messages and commands in that server only as needed to run community features — welcome messages, support answers, release posts, and moderation. It does not maintain message archives outside Discord, and moderation actions are recorded in Discord's own audit log. It does not share or sell any server data.

RoRoRo (game presence)

The RoRoRo Discord application provides game status ("Rich Presence") for users of the RoRoRo launcher. Presence data is generated locally on your machine and displayed by Discord; we operate no server-side collection for it.

What we never do

  • Sell or share your data with third parties.
  • Serve ads or use tracking technologies.
  • Store Discord message content outside Discord.

Your choices

Removing an app from your server, or leaving a server it operates in, ends all processing associated with it. Questions or removal requests: estevan@626labs.dev.

Children

Our Discord applications are intended for users who meet Discord's minimum age requirements.

Changes

If this policy changes, the new version will be posted at this address with an updated effective date.
