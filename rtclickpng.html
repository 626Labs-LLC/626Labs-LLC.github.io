The .webp that won't paste

Some images just don't download and paste. You save a .webp from the web, try to drop it into Teams or Figma, and the app rejects it. You save a .heic from your phone, and your image editor refuses to open it.

The workaround is always the same: find an online converter, upload the file, download a PNG, move it to where you actually needed it.

Right Click PNG replaces that detour with a right-click.

Two verbs where you already are

Right-click any .webp, .avif, .heic, .heif, .jpg, .jpeg, .bmp, .tif, .tiff or .gif in File Explorer.

No separate app to open

Convert to PNG

Saves a PNG next to the original, same base name, new extension.

Copy as PNG

Sends PNG bytes to the clipboard, ready to paste into Teams, Slack, Discord, Figma, Photoshop, Outlook, Word, PowerPoint, OneNote, Paint or Snipping Tool. Works on a .png too, for the paste without opening the file.

The whole selection at once

Multi-select files and the right-click action runs against the whole selection in one shot, with a single summary toast when the batch completes.

Two toggles, one window

A branded settings window with a dark title bar, opened from the Start menu or from the right-click menu itself. Confirm-before-overwrite lives here. Changes apply on the next right-click, no reboot.

Off by default

JPEG when you need it

Convert to JPEG and Copy as JPEG are both there, hidden behind a settings toggle for anyone who needs them.

The shell extension

A Win32 COM server that File Explorer hosts directly, the same way it hosts Windows' own right-click verbs. It stays minimal on purpose: read the selection, read settings, launch the engine, show the toast.

.NET 9 Native AOT

The engine

A standalone converter, called once per invocation. No runtime warm-up. Decoding runs on bundled libwebp, libavif, libheif, libspng and libjpeg-turbo; BMP, GIF and TIFF are read by hand-rolled C#.

MSIX

One package

Signs and packages both, and registers the COM classes and file-type associations. The Store install auto-updates and uninstalls cleanly.

The engine and the shell extension are split across a process boundary on purpose. Explorer loads the extension as a DLL, so a decoder that crashes on a malformed file takes down a short-lived engine process, never Explorer. The extension sees a non-zero exit code and shows an error toast.

Offline by design

Disconnect, and it all still works
No network
No network calls of any kind. No update checks, no phone-home. The engine's P/Invoke bindings carry no HTTP, because there's no HTTP. Read the source and check.
No telemetry
No telemetry, no crash reports, no analytics. No account, no sign-in, no cloud sync. Install it, use it, that's the whole surface.
Original never touched
The original file is never modified, moved or deleted. Convert writes a new file beside it.
Color kept
ICC color profiles are preserved when the source has one. No profile in, no profile out.
Rotation kept
EXIF orientation is baked into the pixel data before the metadata is stripped, so rotated photos stay rotated.
