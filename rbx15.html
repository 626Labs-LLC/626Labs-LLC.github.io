How it's built

A Windows desktop app on a fixed grid

RBX15 is a Windows desktop app built on Electron. Every layer composites onto a canvas locked to the 585×559 template grid Roblox Classic clothing uses, so the PNG you export is the file you upload. When you're done, export a PNG and upload it to Roblox yourself.
