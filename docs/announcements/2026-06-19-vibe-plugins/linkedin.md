```
AI will write you a working app in an afternoon. It will not keep it alive.

The code is the easy part now. The lifecycle around it — scoping, documenting, testing, securing, auditing the prompts it ships, deciding what to build next — is where a vibe-coded afternoon quietly turns into a thing nobody can ship to real users. That's the surface that rots while the demo still runs.

The Vibe family is the answer to that rot: thirteen Claude Code plugins on one shared spine. An opinionated agent that reads your repo before it touches it. No plugin guesses — each reads what's actually there first, then acts. That single rule is the whole thesis.

A few of the thirteen:

- Vibe Cartographer takes an idea to a running app through a build chain you can actually steer — onboard, scope, PRD, spec, checklist, build, iterate, reflect. Not a one-shot generator, not a fleet you can't steer. A sequenced run with you holding the wheel.
- Vibe Sec audits twelve security concerns calibrated to your tier — a weekend prototype isn't held to a fintech bar — then writes the fix and drops a CI gate so the hole stays closed.
- Vibe Test classifies your project's risk, generates the tests that matter, and catches the broken harness cheerfully reporting 0% coverage while you think you're covered.
- Vibe Prompt turns the same lens on the prompts your app ships: structural smells plus a behavioral eval run against your actual production model, because a prompt that reads clean can still misbehave on the model you deploy.

That's four of thirteen. The rest carry docs, onboarding tours, post-ship iteration, feature transplants, long-form research, session wrap-up, and cross-machine retrospectives — the whole arc from idea to maintained.
```
