# The first 626 Day — design

- **Date:** 2026-06-26 (6/26/26 — the first 626 Day in 626 Labs' existence)
- **Status:** approved (design), pending spec review
- **Project:** 626 Labs — Portfolio Hub (`qNCk86nujUfrHEbRU2jy`)
- **Branch (planned):** `feat/626-day` from `origin/main` **after PR #65 (vibe-lingual → 14) merges**

## Why

6/26 is 626 Day. Today is the first one since 626 Labs existed, and it lands on a real
milestone: the whole surface is shipped — **14 Claude Code plugins + 6 Microsoft Store
apps** — with three fresh headliners. We mark it with an outward beat (article + X +
LinkedIn), bring two stale app cards current so the site matches the claim, retire the
now-superseded "thirteen" Field Note, and plant 6/26 as a recurring annual beat.

## Decisions (locked)

1. **Article + posts** (not posts-only). The Field Note is the anchor; X + LinkedIn link to it.
2. **Freshen the RORORO + Sanduhr cards** as part of this — the site must match the post.
3. **Retire the old "thirteen" Field Note** (`draft: true`) — the 626 Day portfolio piece
   supersedes it and it's already stale at "thirteen."
4. **All new content dated 2026-06-26.** (The earlier 06-19 mis-dating is corrected by retiring
   the "thirteen" note; its drafts dir is left as a harmless historical artifact.)
5. **Draft-only socials.** The agent never posts to X or LinkedIn. The article publishes on merge.

## The portfolio (ground truth for all copy)

- **14 Claude Code plugins:** Cartographer, Iterate, Keystone, Doc, Test, Sec, Taker, Walk,
  Wrap, Insights, Thesis Engine, Thesis, Prompt, **Lingual** (the 14th, shipped today).
- **6 Microsoft Store apps:** Sanduhr für Claude, RBX15 Shirt & Pants Maker, Right Click PNG,
  SnapSnip, RORORO, **626 Mod Launcher** (the 6th, just live).
- **Three headliners:**
  - **626 Mod Launcher** — the 6th Store app, just released: a reversible, atomic mod toggler
    (Bethesda / Unreal / FromSoft / BepInEx / Stardew), sealed-core Store build.
  - **RORORO v1.7.1** — matured from v1.4: multi-instance recovery (stop-all-instances +
    reload-on-error), plugin-host hardening (https-only plugin installs), signed
    roblox-compat feed auto-published per release.
  - **Sanduhr v3.1** — a widget overhaul (shipped 06-25): compact mode (collapse to the busiest
    tier), a consolidated hover-lift bottom icon strip + theme flyout, taskbar button that
    tracks pin state, a native rounded close button, range-normalized sparkline. An honest
    "rebuild + sign-in," not invented features.
