# Logos

Este's hand as the company's name, outlined to paths so every file renders without the fonts loaded. Each comes in three inks: `-dark` is `#ffffff` (`ink-0`) for `bg-0` to `bg-3`; `-light` is `#0f1f31` (`brand-navy-deep`) for `ed-paper` and other light grounds; `-duo` is the cyan to magenta gradient for dark marquee moments only (hero, launch, splash), one per page.

## Wordmark (with LLC)

"626Labs" in EsteFont Pro Bold, "LLC" in Space Grotesk 600. Use where the legal entity is meant or the full name earns the space. 40px tall minimum.

- `626labs-wordmark-dark.svg`, `626labs-wordmark-light.svg`, `626labs-wordmark-duo.svg` (duo: "LLC" stays `#ffffff`).

## Signature ("626Labs" only)

The name alone, for app headers, footers and tight spots. 24px tall minimum.

- **Bold** (the default; matches the wordmark): `626labs-signature-bold-dark.svg`, `-bold-light.svg`, `-bold-duo.svg`.
- **Regular** (lighter stroke, the way Este writes it day to day): `626labs-signature-regular-dark.svg`, `-regular-light.svg`, `-regular-duo.svg`. Same 24px minimum; it suits quieter surfaces like the editorial layer or sign-offs.

## 626 mark

The tiny form, for avatars, app icons, tab icons and stamps.

- **Bold**: `626-mark-bold-dark.svg`, `-bold-light.svg`, `-bold-duo.svg`. The default at every size.
- **Regular**: `626-mark-regular-dark.svg`, `-regular-light.svg`, `-regular-duo.svg`. The lighter everyday hand; reads cleanly down to 24px since the EsteFont Pro 3.000 Regular 6 redraw.
- `626-favicon.svg`: the bold mark in `ink-0` on a `brand-navy` rounded square, built to hold at 16 and 32px. Use it for favicons and app icons.

Each file is a single ink (the duo excepted): `<img>` can't recolor it, so pick the file whose ink suits the ground.
