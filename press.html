01Boilerplate

Drop-in copy for an article, a directory listing, or a release note. Take whichever length fits.

One line

626 Labs is a Fort Worth studio building native apps, web tools, and Claude Code plugins.

Short

626 Labs is a Fort Worth, Texas studio that ships native apps, web tools, and Claude Code plugins — including the Vibe family that maps, tests, documents, and ships software alongside you. Tagline: Imagine Something Else.

Long

626 Labs LLC is a builder-run studio out of Fort Worth, Texas, working across native Windows apps, web tools, and a growing family of Claude Code plugins. The work runs from a single principle — that the right tools let one person build at the scale of a team — and it ships in the open, source-first, across the company org and the founder's personal account on GitHub. Imagine Something Else.

06Usage

Do

  • Keep cyan and magenta paired.
  • Place the marks on the navy field or a dark surface.
  • Leave clear space around the mark — at least the height of the icon's center node.
  • Use the files as provided. Scale proportionally.

Don't

  • Recolor, gradient-swap, or split the pair.
  • Stretch, rotate, or add a drop shadow.
  • Add emoji to brand surfaces.
  • Place the mark on a busy photo without the navy field behind it.
